Intra-sheet duplication — Sheet C5 (Ionising Radiation)
Repeated rows IQA0330 C5 "Participant cohort" row appears 9 times with the same UID. Appears to be used as a repeating sub-table header across different procedure cohort blocks (patient, healthy volunteer, radiology imaging, radioactive substances, brachytherapy). Same label, same ID for each block. Medium — likely intentional as a repeating sub-group header within a dynamic table structure, but sharing the same UID will cause issues in a database or form engine. Each cohort block may need a distinct UID suffix or compound key.
Repeated rows IQA0347 IQA0348 IQA0349 IQA0350 IQA0351 IQA0352 C5 Procedure detail fields ("Body part", "Effective dose", "When/how often", "Max examinations", etc.) appear 2–4 times each with the same UID. High — same UID across multiple procedure sub-tables will cause data overwrite in any flat schema. Needs a table/iteration model (e.g. IQA0349[procedure_type]) or unique UIDs per procedure type block.

Radiation — ARSAC & administration
ARSAC
Administration of Radioactive Substances Advisory Committee		 C5 Ionising radiation = Yes (IQA0021), then procedure type includes "diagnostic/therapeutic administration of radioactive substances" (IQA0326) Sheet C5 contains a large dedicated block for ARSAC data (40+ questions). Medical Physics Expert (MPE) must complete dose fields. Dedicated CRE/MPE reviewer request questions (IQA0373, IQA0376). Brachytherapy has its own sub-section. This is the most question-intensive external body in the workbook.
HRA reviewer assignment
CRE / MPE specialist reviewers		 C5 Ionising radiation present — applicant can request specific CRE (Clinical Radiation Expert) or MPE (Medical Physics Expert) reviewers (IQA0373, IQA0376) Unique to the IR module — no equivalent reviewer-request mechanism visible in other modules.
